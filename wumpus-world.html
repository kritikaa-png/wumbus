How to play

Find the gold 💰, then climb out at the entrance 🚪. Pits and Wumpuses kill you. Breeze = a pit is next door. Stench = a Wumpus is next door. Glitter = gold here. Bump = wall. Scream = a Wumpus died.

Keys: arrows/WASD move, Space grabs gold, F then a direction shoots, C climbs, H hint, P pause. An arrow flies until it hits a Wumpus or a wall.

Scoring: gold +1000, exit with gold +1000, kill +200, new safe cell +20, hint −25, revisit (without gold) −5, wall −5, missed arrow −50, death −500. Multipliers: ×1 / 1.2 / 1.5 / 2 / 3.

The AI agent

It starts knowing only the grid size. After every percept it deduces: no breeze means neighbours have no pits, no stench means neighbours have no Wumpus. A cell is safe only when both are ruled out. If a percept cell has exactly one possible source left, that hazard is confirmed. It uses BFS over safe cells to reach the nearest unvisited safe cell, to reach a firing position, and to walk home with the gold. If stuck, it either estimates risk for frontier cells (each shown as a percentage, which is a rough heuristic, not an exact probability) or goes home.

Glossary: percept what the agent senses; inference a conclusion from percepts; frontier unknown cells beside visited ones.
